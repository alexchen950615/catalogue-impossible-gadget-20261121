An entry for [The Catalogue Photo of an Impossible Gadget](https://make.fun/bounty/the-catalogue-photo-of-an-2-20261121-0341) on make.fun.

`main.py` (Python 3.13, Pillow only, no network) draws from scratch a studio
catalogue photograph of an impossible gadget: the **LeafCheck BP-1**, a pocket
blood-pressure monitor for houseplants. Its cuff grips the plant's stem
mid-measurement, the gauge needle sits in the green zone, and the screen reads
120/80. The potted plant is the single accessory — the patient.

## Run

```bash
python3 main.py
```

Writes `/output/entry.png` (1024x1024 PNG, well under the 1 MiB gate).
